# Nihongo Notes

A small, growing home for my Japanese class notes. It keeps useful grammar patterns, vocabulary, and quick references together so they’re easy to come back to.


A small home for my Japanese class notes. It tracks grammar patterns per lesson and some useful reminder sections

## Run it locally

You’ll need [Bun](https://bun.sh/) installed.

```sh
bun install
bun run dev
```

Use `bun run build` to validate the content and make a production build.
